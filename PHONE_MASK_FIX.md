# Исправление маски ввода телефона

## Проблема
Маска телефона постоянно перестраивалась во время ввода, что мешало нормальному вводу номера. Пользователь не мог редактировать номер, удалять символы или вводить их в произвольном порядке.

## Решение

### 1. Разделение событий
- **`<Key>`** - фильтрация ввода (разрешены только цифры и специальные клавиши)
- **`<FocusOut>`** - форматирование по маске (только при потере фокуса)

### 2. Изменения в `gui/dialogs/device_form_parts/widgets_mixin.py`

#### Новый метод `_on_phone_key_press()`
```python
def _on_phone_key_press(self, event=None):
    """Обработка нажатий клавиш в поле телефона.
    
    Разрешает только цифры, Backspace, Delete и навигацию.
    """
    # Разрешаем специальные клавиши
    if event.keysym in ('BackSpace', 'Delete', 'Left', 'Right', 'Home', 'End', 'Tab'):
        return None
        
    # Блокируем все кроме цифр
    if not event.char.isdigit():
        return 'break'
        
    return None
```

#### Улучшенный метод `_format_phone_input()`
- Применяется **только** при событии `FocusOut` (потеря фокуса)
- Во время ввода поле не изменяется
- Автоматически добавляет код страны `+7` если номер начинается с `8` или не содержит код
- Корректно обрабатывает частичный ввод (1-10 цифр)

#### Логика форматирования
| Ввод | Результат |
|------|-----------|
| `89991234567` | `+7 (999) 123-45-67` |
| `9991234567` | `+7 (999) 123-45-67` |
| `9991234` | `+7 (999) 123-4` |
| `999` | `+7 (999` |
| `+7` | `+7` |
| Пустое | (не изменяется) |

### 3. Изменения в `gui/dialogs/employees.py`

Добавлена поддержка маски телефона для поля ввода телефона сотрудников:

```python
self.phone_entry = self._labeled_entry(form, "Телефон:", phone_mask=True)
```

Метод `_labeled_entry()` теперь принимает параметр `phone_mask` и автоматически привязывает обработчики.

## Преимущества нового подхода

1. **Удобство ввода**: пользователь может свободно редактировать номер
2. **Визуальная обратная связь**: форматирование применяется когда пользователь закончил ввод
3. **Защита от ошибок**: нельзя ввести буквы или специальные символы
4. **Автоматическое исправление**: `8` автоматически заменяется на `+7`
5. **Кроссплатформенность**: работает на Windows, macOS и Linux

## Тестирование

Все 10 тестов пройдены:
- ✅ Полный номер с `8`
- ✅ Полный номер без кода
- ✅ Номер с буквами (очищается)
- ✅ Частичный ввод (3, 4, 7, 9 цифр)
- ✅ Пустое поле
- ✅ Только `+7`

## Использование

```python
# В форме устройства (автоматически через widgets_mixin.py)
self.phone_entry.bind("<FocusOut>", self._format_phone_input)
self.phone_entry.bind("<Key>", self._on_phone_key_press)

# В форме сотрудников
self.phone_entry = self._labeled_entry(form, "Телефон:", phone_mask=True)
```
