### 🚀 Ключевые Возможности

#### 1. Авто-Обнаружение Модулелей
```python
registry = ModuleRegistry(modules_path=Path("./modules"))
discovered = registry.discover_modules()
# Автоматически находит все папки с __init__.py
```

#### 2. Жизненный Цикл
```
on_init() → on_start() → [работа приложения] → on_stop()
```

#### 3. DI Интеграция
```python
class MyModule(ModuleBase):
    def on_start(self):
        order_service = self.get_service("order_service")
        client_repo = self.get_repository("client_repository")
```

- Ошибки в модуле не ломают ядро

### 🎯 Примеры Использования

#### Сценарий 1: Telegram Бот для Уведомлений

```python
# modules/telegram_bot/__init__.py
class TelegramBotModule(ModuleBase):
    def on_start(self):
        config = self.get_service("config_service")
        token = config.get("telegram.token")
        asyncio.create_task(self.run_bot(token))
```

**Результат**: Через 2 часа после начала разработки бот работает.

#### Сценарий 2: Панель Аналитики с Графиками

```python
# modules/analytics_dashboard/__init__.py
class AnalyticsModule(ModuleBase):
    def register_gui_components(self, factory):
        factory.register_panel("charts", ChartsPanel)
```

**Результат**: Новый раздел в GUI без изменения main_window.py

#### Сценарий 3: Интеграция с 1С

```python
# modules/integration_1c/__init__.py
class Integration1CModule(ModuleBase):
    def on_start(self):
        scheduler = self.get_service("scheduler")
        scheduler.every().hour.do(self.sync_with_1c)
```

**Результат**: Фоновая синхронизация без блокировки UI

### 🔧 Технические Детали

#### ModuleBase API

| Метод | Описание | Вызывается |
|-------|----------|------------|
| `on_init()` | Инициализация | При загрузке модуля |
| `on_start()` | Запуск | После старта приложения |
| `on_stop()` | Остановка | Перед закрытием приложения |
| `register_gui_components()` | GUI интеграция | При инициализации GUI |
| `register_routes()` | API роуты | При настройке HTTP сервера |

#### ModuleRegistry API

| Метод | Возвращает | Описание |
|-------|-----------|----------|
| `discover_modules()` | List[str] | Сканирование папки |
| `initialize_all(container)` | Dict[str, ModuleBase] | Инициализация |
| `start_all()` | None | Запуск всех |
| `stop_all()` | None | Остановка всех |
| `get_module(name)` | Optional[ModuleBase] | Получить по имени |
| `list_modules()` | List[Dict] | Список с метаданными |
