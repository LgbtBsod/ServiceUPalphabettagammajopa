# Исправление маски ввода номера телефона

## Проблема
При вводе номера телефона `+79376396173` маска постоянно перестраивалась во время ввода, что мешало нормальному вводу цифр по одной. Пользователь не мог комфортно ввести номер.

## Решение

### Измененный файл
`gui/dialogs/device_form_parts/widgets_mixin.py`

### Ключевые изменения

#### 1. Метод `_format_phone_input()`
**ДО:** Форматирование применялось при каждом событии ввода, вызывая постоянное перестроение маски.

**ПОСЛЕ:** Форматирование применяется **ТОЛЬКО при потере фокуса** (`FocusOut` event).

```python
def _format_phone_input(self, event=None):
    """КРИТИЧЕСКИ ВАЖНО: Применяется ТОЛЬКО при потере фокуса!"""
    
    # Проверяем тип события - форматируем ТОЛЬКО при FocusOut
    event_type = getattr(event, 'type', None) if event else None
    if event_type != 'FocusOut':
        return  # Не делаем ничего во время ввода!
    
    # ... остальная логика форматирования ...
```

#### 2. Метод `_on_phone_key_press()`
**ДО:** Содержал избыточную логику с проверкой текущих цифр.

**ПОСЛЕ:** Простая фильтрация - разрешает только цифры и специальные клавиши.

```python
def _on_phone_key_press(self, event=None):
    """Разрешает только цифры и управляющие клавиши."""
    
    # Разрешаем специальные клавиши управления
    allowed_keys = ('BackSpace', 'Delete', 'Left', 'Right', 'Home', 'End', 'Tab')
    if event.keysym in allowed_keys:
        return None
        
    # Разрешаем ввод цифр
    if event.char and event.char.isdigit():
        return None
        
    # Блокируем все остальное
    return 'break'
```

## Как это работает теперь

### Сценарий ввода номера +79376396173:

1. **Пользователь начинает вводить:** `9`
   - Поле содержит: `9`
   - Маска НЕ применяется

2. **Продолжает ввод:** `93`
   - Поле содержит: `93`
   - Маска НЕ применяется

3. **Вводит дальше:** `9376396173`
   - Поле содержит: `9376396173`
   - Маска НЕ применяется

4. **Пользователь переходит на другое поле (FocusOut):**
   - Срабатывает `_format_phone_input()`
   - Номер нормализуется: добавляется `7` в начало → `79376396173`
   - Применяется маска: `+7 (937) 639-61-73`
   - Поле обновляется отформатированным значением

5. **Если пользователь возвращается и редактирует:**
   - Может удалять любые символы
   - Может добавлять новые цифры
   - Маска снова применится только при уходе из поля
